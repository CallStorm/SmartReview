# 配置用 Excel 模版优化与模版管理页下载

**日期：** 2026-08-28  
**状态：** 待用户审阅  
**范围：** 配置侧客户/管理员使用的专项方案审核配置 Excel；模版管理页提供下载与简短说明。不做 Excel 自动导入。

## 背景与目标

客户当前通过 Excel「专项方案审核模版」整理审核配置，再由人工录入 SmartReview。系统不解析 Excel；Word `.docx` 才是结构模版来源。

目标：

1. 优化 Excel 字段，与系统实际能力对齐（含图审核）。
2. 在模版管理页提供空白模版 + 落地脚手架示例下载。
3. 页左下角放简短指导说明（不做独立指引页/Modal）。

## 决策摘要

| 项 | 决定 |
|----|------|
| 受众 | 配置侧客户/管理员 |
| 下载入口 | 模版管理页（页级，不绑单行方案类型） |
| 提供文件 | 空白通用模版 + 落地脚手架示例 |
| 图审核列 | 拆成：启用 / 有无图 / 图种类 / 图内容 |
| 编制依据审核列 | **不加** |
| 填写指引 | **不要**独立大纲/Modal；左下角说明文即可 |
| 行内下载按钮 | 改名为「下载 Word」 |
| Excel 导入 | 不做 |
| 管理员手册附录同步 | 本期不做 |

## Excel 工作表结构（6 张）

删除整张「审核流程图」。空白与示例表头一致。

### 1. 说明与版本

| 字段名 | 说明 |
|--------|------|
| 方案大类 | 如：脚手架工程 |
| 方案名称 | 如：落地脚手架 |
| 适用说明 | 可选 |
| 编制人 | 可选 |
| 更新日期 | 可选 |

去掉：模版版本、方案类型代码、填写约定区块。

建议在表顶或适用说明旁注明：本文件为配置清单，系统不自动导入。

### 2. 章节结构_完整性

保持：`章节编码`、`章节标题`、`是否校验`、`完整性依据`、`备注`。  
用途：与 Word 标题树对照；系统侧由上传 Word 生成节点，不按 Excel 编码入库。

### 3. 编制依据库

保持现有列（依据ID、文献类型、标准号或文号、文献名称、版本或施行日期说明、是否必引、类别、分类、备注）。

### 4. 一致性规则

保留：规则ID、规则名称、是否启用、源章节编码、目标章节编码、检查说明。  
去掉：严重等级（系统由模型输出严重度，不存模板配置）。  
示例文案需去掉基坑残留表述。

### 5. 章节审查配置

| 列 | 说明 |
|----|------|
| 章节编码 | 与章节结构表一致 |
| 依赖章节编码 | 内容审核引用；多依赖可多行同编码展开 |
| 知识库引用 | 如 `知识库:脚手架工程 tag:落地脚手架` |
| 人工提示词 | 含原「数值审核/审查侧重点」类要求，写入本列 |
| 图审核启用 | 是/否 |
| 有无图 | 启用后可选填审核要求 |
| 图种类 | 启用后可选填 |
| 图内容 | 启用后可选填 |

去掉：数值审核、审查侧重点。  
不加：编制依据审核列。

### 6. 知识库

保持现有列。

## 模版管理页 UI

1. **页级工具区**（列表上方）：  
   - 下载空白配置模版 → `/config-templates/专项方案审核配置模版_空白.xlsx`  
   - 下载落地脚手架示例 → `/config-templates/专项方案审核配置模版_落地脚手架示例.xlsx`
2. **行内按钮**：原「下载」→「下载 Word」（仍走现有 Word 预签名下载）。
3. **左下角说明文**（约 2～4 行 secondary 文案），大意：  
   配置用 Excel 请下载空白或示例填写后，在本页按方案类型手工录入（系统不自动导入）；章节结构以 Word 标题为准；图审核填对应列并在工作流中开启。
4. 不新增后端 API；不做填写指引 Modal / 独立 md 页面。

## 与系统字段对照（录入时）

| Excel | 系统 |
|-------|------|
| 方案大类 / 方案名称 | 方案类型管理 `category` / `name` |
| 章节结构 | Word 上传 → 标题树 |
| 编制依据库 | 编制依据管理 |
| 一致性：源/目标 + 检查说明 | 节点 `context_consistency_ref_node_ids` + `context_consistency_prompt` |
| 依赖章节 / 知识库 / 人工提示词 | `ref_node_ids` / Dify+keywords / `review_prompt` |
| 图审核四列 | 节点 `image_review.enabled` + existence/kind/content + note；工作流开 `image_review` |

- 无「审核流程图」sheet；无严重等级、数值审核、审查侧重点列；有图审核四列。  
- 行内 Word 下载文案为「下载 Word」；左下角有简短说明。  
- 行为仍为人工录入，无导入接口。
